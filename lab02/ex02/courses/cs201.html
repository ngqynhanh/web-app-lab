CS201: Data Structures & Algorithms

Credits: 4

Instructor: Dr. Nguyen Van A (nguyenvana@hcmiu.edu)

Schedule: Tuesdays & Thursdays, 11:00 AM - 12:30 PM

Location: A1, Room 204

Course Description

In-depth study of fundamental abstract data types and algorithmic structures. Topics include arrays, linked lists, stacks, queues, binary trees, hash tables, sorting algorithms, and basic asymptotic Big-O time complexity analysis.

Prerequisites

CS101 or equivalent programming background.
